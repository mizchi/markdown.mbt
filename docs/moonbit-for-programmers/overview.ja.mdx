## MoonBit の位置づけ

MoonBit は WebAssembly を主軸に、JavaScript と native も対象にする静的型付き言語です。小さな実行環境へ予測しやすいプログラムを届けるため、型、パターンマッチ、明示的な API 境界を重視します。

最初の目的は既存の知識を置き換えることではなく、MoonBit の構文とツールチェーンに対応付けることです。プロジェクトは `moon new` で始め、`moon check` と `moon test` を短いフィードバックループにします。
