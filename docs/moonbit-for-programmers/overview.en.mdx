## Where MoonBit fits

MoonBit is a statically typed language centered on WebAssembly, with JavaScript and native targets as well. It emphasizes types, pattern matching, and explicit API boundaries for predictable programs in small runtime environments.

The initial goal is not to replace what you know. Map familiar concepts to MoonBit syntax and tooling, start a project with `moon new`, then keep `moon check` and `moon test` in a short feedback loop.
